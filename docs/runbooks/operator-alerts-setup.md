# הגדרת התראות למפעיל — צעד אחר צעד

> יש גם מדריך מרוכז לכל ארבע הבעיות הפתוחות, בסדר שבו צריך לפתור אותן:
> [`owner-step-by-step.md`](./owner-step-by-step.md). ההתראות הן בעיה 3 שם.

עד עכשיו המערכת לא שלחה שום התראה. הסיבה: ערוץ ההתראות היחיד שהיה מחווט הוא
טלגרם, טלגרם מעולם לא הוגדר בפרודקשן, והפונקציה שמנסה לשלוח מחזירה בשקט
`{skipped:'no_token'}`. כלומר עשרה מקומות בקוד "שלחו התראה" ואף אחת מהן לא
יצאה — ושום דבר לא התלונן.

עכשיו יש שלושה ערוצים: **וואטסאפ**, **מייל (Resend)** וטלגרם (אופציונלי).
מספיק להגדיר אחד; מומלץ שניים, כדי שכשל בערוץ אחד לא ישאיר אותך עיוור.

הגדרה חד-פעמית, בערך 6 דקות.

---

## שלב 1 — מפתח Resend (למייל)

1. היכנס ל-<https://resend.com/api-keys>
2. **Create API Key** → שם: `karnaf-crm-alerts` → הרשאה: **Sending access**
3. העתק את המפתח **מיד** — Resend מציג אותו פעם אחת בלבד.

### כתובת השולח

Resend דורש דומיין מאומת כדי לשלוח מכתובת משלך:

- **אם יש לך דומיין מאומת** ב-<https://resend.com/domains> — השתמש ב-
  `alerts@<הדומיין שלך>`.
- **אם אין** — השתמש ב-`onboarding@resend.dev`. זו כתובת בדיקה של Resend
  שעובדת מיד, אבל היא שולחת **רק לכתובת המייל של בעל חשבון ה-Resend**. להתראות
  אליך זה מספיק לחלוטין; אם בעתיד תרצה לשלוח למישהו נוסף, תצטרך לאמת דומיין.

| שם הסוד | ערך | לְמה |
|---|---|---|
| `ALERT_WHATSAPP_TO` | `972559966175` | וואטסאפ אליך. פורמט בינלאומי, **בלי** `+` ובלי מקפים |

## שלב 4 — אימות (זה החלק שלא היה קיים קודם)

בכרטיס ליד או מכל מקום בממשק, הרץ את הפעולה `test_alert_channels` (owner/admin
בלבד). היא מדווחת אילו ערוצים מוגדרים **ושולחת הודעת בדיקה אמיתית לכל אחד**.

התשובה נראית כך:

```json
{
  "ok": true,
  "configured": { "whatsapp": true, "email": true, "telegram": false },
  "delivered": true,
  "channels": {
    "whatsapp": { "ok": true, "detail": "template:karnaf_followup_v1" },
    "email":    { "ok": true },
    "telegram": { "ok": false, "skipped": "no_token" }
  }
}
```

`delivered: true` פירושו שלפחות ערוץ אחד קיבל את ההודעה. כל ניסיון נרשם בטבלה
`operator_alerts` עם התוצאה לכל ערוץ — כך שאם בעתיד "לא הגיעה התראה", יש איפה
לבדוק אם בכלל ניסינו ומה הספק ענה.

### על חלון 24 השעות בוואטסאפ

מטא מאפשרת לשלוח טקסט חופשי רק בתוך 24 שעות מההודעה האחרונה של הנמען. המספר
שלך (0559966175) כנראה לא כתב למספר העסקי, ולכן ההתראה הראשונה תצא **כתבנית
מאושרת** (שורה אחת, עד 600 תווים). **אם תשיב להתראה הזו בוואטסאפ** — ייפתח חלון
של 24 שעות, וכל ההתראות הבאות יגיעו כטקסט מלא ומעוצב. המערכת מנסה טקסט חופשי
קודם ונופלת לתבנית רק כשצריך, אז זה קורה מעצמו.

**המייל אינו כפוף לשום מגבלה כזו** — ולכן שווה להגדיר את שניהם.
